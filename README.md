# עץ מרקט — אתר חנות (דמו)

אתר חנות סטטי (HTML/CSS/JS, עברית RTL) למחסן עצים מירכא — פרויקט בדיקה לסקיל עיצוב האתרים.

הרצה מקומית (Windows): להריץ `פתיחת-האתר.bat` או
`powershell -File serve.ps1 -Root . -Port 8830` ולפתוח http://localhost:8830/

הערות:
- הפונטים בתיקיית `fonts` מסחריים ברישיון — לא להפיץ את הריפו באופן ציבורי.
- תמונות המשפחה/הפרויקטים/הצוות נוצרו ב-AI ומיועדות להחלפה בצילומים אמיתיים.
- הטקסטים המשפטיים (תקנון, פרטיות, החזרות, נגישות) הם טקסטי דוגמה לבדיקת עו״ד.
- הקופה היא דמו ואינה גובה תשלום.

- תיקיית `fonts` (פונטים מסחריים) לא נכללת בריפו. להרצה מלאה יש להעתיק אליה את קבצי Birzia-Black ו-FbAbsolutiHeb (Light/Medium/Bold) בפורמט woff/woff2.
